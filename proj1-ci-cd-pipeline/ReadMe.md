# Project 1: Reusable CI/CD Framework
Build a reusable multi-environment CI/CD framework using:
1. GitHub Actions
2. Docker
3. AWS ECR, IAM, CloudWatch
4. AWS ECS deployment

## Features

1. Build pipeline
2. Docker image creation
3. Push to ECR
4. Automated deployment
5. Environment promotion: dev, qa, prod
6. Rollback support

## Deliverables
[ ] GitHub Actions workflow
[ ] Reusable deployment templates
[ ] Parameterized pipeline

## Reusable Component
This becomes: “Drop-in enterprise CI/CD framework”

### Can be reused in:
- Microservices
- APIs
- Java apps
- Python apps
- Node.js apps

## Enterprise Value
- Demonstrates DevOps maturity
- Deployment automation
- Release engineering
- CI/CD governance
